A Version Control System is a tool used to track and manage code.

1. CVCS:

We can pull only for latest changes.

2. DVCS:

We can pull all repository with backup.




## Github:

Github is a Code hosting server for github repos.
It's allow developer to store code and manage different version of code.


## Repository:

Repository is a place that helps you to store and manage different version of code.



## git reset.
git reset is used to go back to a previous commit.
git reset --hard HEAD~1

## git revert.
git revert is used to undo the changes of a commit.
git revert <commit-id>

## git rebase.
git rebase is use to make all commit history in liner.

## git merge.
git merge is use to merge two different branchs.

## Pull Request.

A Pull Request is use to merge code from one branch into another branch.
