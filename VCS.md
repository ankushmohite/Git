A Version Control System is a tool used to track and manage changes in code.

1. CVCS:

We can pull only for latest changes.

2. DVCS:

We can pull all repository with backup.




## Github:

Github is a Code hosting server for github repos.
It's allow developer to store code and manage different version of code.


## Repository:

Repository is a place that helps you to store and manage different version of code.
