## Merge conflict

when multiple developers make changes to the same line or same part of a particular file, and Git cannot automatically determine which change is correct.

## How to resolve merge conflict.

First, the developer checks the conflicted files and identifies what the conflict is and which changes should be kept. Then, he discusses with the other developer and comes to a conclusion about the correct changes. After that, he opens the conflicted file, removes the unwanted code and keeps the required code. Finally, he adds the resolved file using git add and commits the changes using git commit.

## What is Git Fork?
